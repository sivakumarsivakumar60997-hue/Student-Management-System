# 🎓 Student Record Management System

## 📌 Project Overview

The **Student Record Management System** is a console-based Java application designed to manage student information and academic records. It allows users to add student details, search for students, update attendance and subject marks, and generate report cards.

This project demonstrates the use of Java programming concepts, object-oriented programming, collections, loops, and conditional statements.

## ✨ Features

- ➕ Add new student records
- 📋 Display all student details
- 🔍 Search students by roll number
- 📅 Update student attendance
- 📝 Update subject-wise marks
- 🧮 Calculate total marks and percentage
- 🏆 Calculate grades automatically
- ✅ Check PASS/FAIL results
- 📄 Generate student report cards
- ⚠️ Validate marks and attendance
- 🔐 Prevent duplicate roll numbers

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Collections:** ArrayList
- **Input Handling:** Scanner
- **Control Statements:** If-else and switch
- **Loops:** For loop and do-while loop
- **IDE:** Visual Studio Code

## 📚 Subjects

The application manages marks for five subjects:

1. ADIC
2. MPMC
3. IQTA
4. AWP
5. JAVA

Each subject is evaluated out of 100 marks.

## 📊 Grading System

| Percentage | Grade |
|---|---|
| 90–100% | S |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| 35–49.99% | E |
| Below 35% | F |

**Result:** A student passes only if they score at least 35 marks in every subject.

## ▶️ How to Run the Project

### Step 1: Install Java

Install the Java Development Kit (JDK) on your computer.

### Step 2: Download the Project

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Alternatively, download the repository as a ZIP file from GitHub.

### Step 3: Open the Project

Open the project folder in Visual Studio Code or your preferred Java IDE.

### Step 4: Compile the Program

Open the terminal in the folder containing `StudentManagementSystem.java` and run:

```bash
javac StudentManagementSystem.java
```

### Step 5: Run the Program

```bash
java StudentManagementSystem
```
